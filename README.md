# 🚀 Digitools (Learning Project)

## 📌 Project Description

Digitools is a frontend learning project where I practiced building a responsive UI using React. The main goal of this project is to understand how to display JSON data as products, manage cart functionality, and improve overall UI design skills.

This is not a production-ready application, but a practice project to strengthen core React concepts.

---

## 🛠️ Technologies Used

* ⚛️ React.js
* 🎨 Tailwind CSS
* 🌼 DaisyUI
* 🔔 React Toastify
* 🎯 Iconify Icons
* 📦 JSON (Local Data)

---

## ✨ Features

* 🧾 Display products dynamically from JSON data
* 🛒 Add to cart & remove from cart functionality
* 🔔 Toast notifications using React Toastify
* 🎯 Used Iconify icons for modern UI visuals
* 📱 Fully responsive design for mobile, tablet, and desktop
